    Set Up Basemap

    We will first set up the basemap based on what we covered in Lab 1.

    • To stay organized, it is recommended to create a new file folder to save your Lab 2 HTML file and the icon image to be added later.
    • Open your code editor, copy and paste the following lines to set up the basemap using the standard map tiles from OpenStreetMap.

      Please spend some time to go over these lines and make sure you understand what each line does. Note that we covered all these in Lab 1. 

      <!DOCTYPE html>
<html>
    <head>
        <title>Lab 2</title>

         <link rel="stylesheet" href="https://unpkg.com/leaflet@1.9.4/dist/leaflet.css"
           integrity="sha256-p4NxAoJBhIIN+hmNHrzRCf9tD/miZyoHS5obTRR9BMY="
           crossorigin=""/>

         <script src="https://unpkg.com/leaflet@1.9.4/dist/leaflet.js"
           integrity="sha256-20nQCchB9co0qIjJZRGuk2/Z9VM+kNiyxNV1lvTlZBo="
           crossorigin=""></script>

    </head>

    <body>
        <div id="map" style="height: 500px"></div>

        <script type="text/javascript">

          var map = L.map('map', {
              center: [38.16, -96.96],
              zoom: 4
          });

          L.tileLayer('https://server.arcgisonline.com/ArcGIS/rest/services/Canvas/World_Light_Gray_Base/MapServer/tile/{z}/{y}/{x}', {
               attribution: 'Tiles &copy; <a href="https://www.esri.com/">Esri</a>',
               maxZoom: 4,
               minZoom: 4
            }).addTo(map);

        </script>
   </body>
</html>
    • Then, save the document as map2.html in your Lab 2 folder. Please remember to specify the file extension as .html to make it work. Your map should look like:

    • You may have noticed that the map is not zoomable. That is because we have set the maxZoom and minZoom to be the same, i.e., 4. That way, we could "lock" the map to a certain scale.
    • Look closely at the end of the tile address: {z}/{y}/{x}. This service places y before x. Some other tile services use {z}/{x}/{y} instead. If you copy a tile address from somewhere else, check the order. If the order is wrong, the map still loads, but it draws the wrong part of the world.
    • This basemap is hosted by Esri. It is free to use and does not require an account. The tiles are available up to zoom level 16.

    Add Markers

    Now, we already have the basemap set up and we could add some other things to the map.

    • Let us first add a marker for Chicago. The L.marker function of Leaflet is used to put markers on the map.
      Place the following line to the script section, AFTER the adding tile layer part: 
      
var marker1 = L.marker([41.98,-87.72]).addTo(map);
      The latitude and longitude of Chicago were used to define the geographic location for placing the marker. Similar to adding tiles, addTo(map) adds the markers to the map variable which holds the initialized map.

        
      The semicolon ; in JavaScript is used to separate statements. A statement is a piece of code that tells the computer to do something. However, ending statements with a semicolon is not required, but highly recommended.

      Also note that we have assigned the marker to a variable called marker1. We have been using variable since Lab 1. JavaScript variables are containers for storing data values to be used at a later time.
      • In the earlier example of the map variable, we used it whenever we added content to the map area, e.g., tile layer, marker.
      • In this particular example, this marker1 variable will be used later for binding popup to the marker.

    • Following this structure, we can add more markers to the map. For example, the following line adds another marker for Tallahassee, FL. 
      
var marker2 = L.marker([30.44,-84.3]).addTo(map);
      We have assigned the marker to another variable called marker2 so that it will not overwrite the existing marker for Chicago.

    Add Popups

    Popups are often used when you want to attach some information to a particular object on a map. Here, let's attach popups to the markers using the Leaflet bindPopup method.

    • Following the two lines of adding markers, add: 
      
marker1.bindPopup("work at NEIU");
marker2.bindPopup("went to FSU for graduate school");

      We attached the popups to each marker (marker1 and marker2) with the text in the quotes. Single and double quotes work the same here.

    • Click on each marker, their popups should appear.

    • What about inserting pictures in the popup?
      • Basically, the bindPopup method allows any content structured using HTML to be inserted inside the parentheses (). The HTML code needs to be surrounded by quotes.
      • If you have learned some HTML, you would know that the img tag (learn the tag first) is used to format an image in HTML. We use it to insert a picture to the popup here. REPLACE the two lines of bindPopup with the following:
        • 
var pic1 = '<img src="https://upload.wikimedia.org/wikipedia/commons/6/68/NEIU_Sci.jpg" alt="BBH" width="250">';
var pic2 = '<img src="https://upload.wikimedia.org/wikipedia/commons/3/36/FSUWestcottBuilding-2.jpg" alt="FSU" width="250">';

marker1.bindPopup(pic1);
marker2.bindPopup(pic2);
      • These two lines are long and will wrap onto several lines in the box above. In this example, I used the variables pic1 and pic2 to hold the HTML formatted images.
      • For the image source (the src attribute), I found pictures from Wikimedia Commons' public domain and used the image urls as the sources. You may use your own images and save them in your Lab 2 folder, then link to them through a file path. Or you can host your images via imgur or other platforms. Just make sure to use the URL that links to the actual image file, not a web page.
      • The alt attribute specifies alternate text for the image. It is displayed if the image fails to load, and it is what a screen reader reads aloud in place of the picture. Write something that describes the image, such as alt="Bernard Brommel Hall at NEIU". Avoid empty or generic text such as alt="image", because it tells the reader nothing.
      • In addition, I also defined the width of the image (in pixels). I did not specify the height, which will be calculated proportionally by default.

    • Using HTML, you could also combine different contents in your popups and format them in your desired manner. Try the example below: 
      
var pic1 = '<img src="https://upload.wikimedia.org/wikipedia/commons/6/68/NEIU_Sci.jpg" alt="BBH" width="250">';
var pic2 = '<img src="https://upload.wikimedia.org/wikipedia/commons/3/36/FSUWestcottBuilding-2.jpg" alt="FSU" width="250">';

marker1.bindPopup('work at NEIU' + '<br>' + pic1);
marker2.bindPopup('went to FSU for graduate school' + '<br>' + pic2);
      The + sign is used to combine contents. Note the br tag is used to insert a line break between the text and the image.
    • The example below changes colors and font weight of the text using the style attribute inside a p tag: 
      
var pic1 = '<img src="https://upload.wikimedia.org/wikipedia/commons/6/68/NEIU_Sci.jpg" alt="BBH" width="250">';
var pic2 = '<img src="https://upload.wikimedia.org/wikipedia/commons/3/36/FSUWestcottBuilding-2.jpg" alt="FSU" width="250">';

marker1.bindPopup('<p style="color:blue; font-weight:bold"> work at NEIU </p>' + pic1);
marker2.bindPopup('<p style="color:seagreen; font-weight:bold"> went to FSU for graduate school</p>' + pic2);

      By the way, I like this site for picking HTML colors.

    • Practice your HTML knowledge and try more on your own to customize the popups!

    Customize Marker Icons

    In Leaflet, the blue locator icon is used by default for displaying the markers. However, it is also possible to use your own custom icons.

    • Prepare the image to be used as the custom icon. Ideally, the icon image should have a transparent background. PNG is the safest choice and is what most icon sites provide. Do not use JPEG, because JPEG does not support transparency and your icon will appear inside a white box.
    • As an example, I am using an image icon university.png downloaded from https://www.flaticon.com/

      To test things out first, you may right-click the sample image above and save the image to your Lab 2 folder.
    • Make sure to save the icon image file in the SAME folder as the html file.
    • Marker icons in Leaflet are defined by L.icon objects.
      Place the following lines right BEFORE adding the markers ( i.e., above the L.marker functions; Defining the icons before adding the markers allows us to use these custom icons when adding the markers): 
      
var universityIcon = L.icon({
    iconUrl: 'university.png', // url that links to the icon image file, saved in the same folder as the current page 
    iconSize:     [38, 38], // size of the icon image in pixels
    iconAnchor:   [19, 19], // the top left corner of the icon will be aligned so that this point is at the marker's geographical location
    popupAnchor:  [0, -10] // point from which the popup should open, relative to the iconAnchor
});

      The explanation of each line is provided as JavaScript comments, starting with //, which will not be executed. And you may want to read these comments carefully and let me know if you have any questions.

      • The most important element when defining a custom icon is the image file (iconUrl). In this case, we saved the image file in the same folder as the html file so we could link to it by the file name (relative url). You may use absolute url of a hosted image file (Refer to the HTML File Paths tutorial).
      • It is often necessary to adjust the size (iconSize) and alignment (iconAnchor) of the icon, as well as the alignment of the popup (popupAnchor).

    • Note that we have defined a variable universityIcon to hold the custom icon so that we could use it when adding the markers.
      Modify/replace the lines for adding the markers: 
      
var marker1 = L.marker([41.98,-87.72], {icon: universityIcon, alt: 'Northeastern Illinois University'}).addTo(map);
var marker2 = L.marker([30.44,-84.3], {icon: universityIcon, alt: 'Florida State University'}).addTo(map);

      Basically, we added {icon: universityIcon} to draw the markers using our custom icon: the universityIcon variable. A comma , was used as a separator within a statement.

      We also added a second option, alt. A custom icon is just a picture, so it needs alternate text for the same reason the popup images do. Without it, Leaflet uses the word Marker, which tells a screen reader user nothing about the place. Notice that the two options are separated by a comma inside the same { } braces.
